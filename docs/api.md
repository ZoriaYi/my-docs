# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：`/api/docs`
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [{ "id": 1, "title": "使用指南" }]
}
```

## 接口说明表

| 字段            | 类型   | 说明         |
| --------------- | ------ | ------------ |
| `items`         | 数组   | 文档条目列表 |
| `items[].id`    | 整数   | 文档编号     |
| `items[].title` | 字符串 | 文档标题     |

## 说明

本页的接口和返回示例只用于练习文档编写，不对应真实后端服务。实际项目中，接口文档应和代码一起维护，并在修改接口时同步更新。
