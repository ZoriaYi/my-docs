# 我的技术文档

欢迎访问我的个人文档网站。本网站使用 MkDocs 构建，通过 GitHub Actions 自动部署到 GitHub Pages。

自动部署验证：这是我第二次推送后更新的内容。

- [使用指南](guide.md)
- [API 参考](api.md)

## 为什么做这个网站

平时写笔记时，内容分散在多个 Markdown 文件里，本地能看，但不方便分享。这次实践把 Markdown 文档构建成静态网站，再通过 GitHub Actions 自动发布到 GitHub Pages。这样每次修改文档并推送后，网站会自动更新，不需要手工上传网页文件。
